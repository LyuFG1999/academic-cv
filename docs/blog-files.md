# 博客文件与本地导入

在后台的“博客”面板新建或展开文章。正文使用 Markdown；“文章文件”集中管理图片、文档和外部 HTTP(S) 下载链接。

- **复制 URL**：完整网址，可用于分享或粘贴到其他编辑器。
- **复制插入链接**：图片生成 `![说明](地址)`，其他文件生成 `[名称](地址)`。
- **插入正文**：在正文光标位置插入相同的 Markdown。
- **加入文末下载区**：使用同一个文件，不重复上传；下载名称可以单独编辑。
- **移出文件列表**：先移除正文和下载区中的引用；已发布的文件不会从仓库物理删除，以免破坏其他链接。

上传和本地导入仅暂存在当前后台。保存本地草稿不会部署。点击“发布修改”后，文章、文件和设置一次提交；部署完成后文件 URL 才能访问。

## 本地文件

**MD**：UTF-8 编码，最多 2 MB。解析正文；可从 YAML 读取标题、日期、摘要、语言和标签。导入替换正文前会确认，已有文件列表保留。含本地图片的文章应使用 ZIP 导入；单独上传 MD 无法读取电脑上的相邻文件。

**ZIP**：压缩包最多 40 MB，结构必须如下（不支持额外的最外层目录）：

```text
article.zip
├── article.md
└── assets/
    ├── figure.png
    └── report.pdf
```

正文引用示例：

```md
![研究示意图](./assets/figure.png)
[下载报告](./assets/report.pdf)
```

也支持 Markdown 引用式链接。仅正文实际引用的资源进入文章专属 `uploads/blog/<文章标识>/` 目录，引用自动替换为新路径。代码块里的示例引用和未使用图片不会触发上传。资源文件名可含中文或空格，上传后转换成安全且不重名的名称。

ZIP 解压后单文件最多 20 MB、总大小最多 100 MB、最多 300 个条目。路径越界、重复条目、缺少资源及可执行 HTML 会被拒绝。请用 Markdown 图片/链接语法，不用原始 HTML img/a 标签。支持常见图片（PNG/JPEG/WebP/GIF/AVIF）与 PDF、Office、CSV、TXT、ZIP 文件；不接受脚本、HTML、SVG 作为上传资源。

## 本轮修复与验证

- 构建失败原因：YAML 的未加引号日期被解析为 Date，旧的博客 schema 只接受 string。现在兼容 Date，并在后台输出带引号日期。
- 更新 checkout 与 Astro 构建 Action，消除旧 Node.js 20 Action 警告；应用构建仍使用 Node 22。
- 页面淡入 90 ms，内容浮现 150 ms，避免重复注册内容观察器。首页和研究页共用研究领域图标选项。
- 自动测试覆盖导入、引用路径重写、未使用资源过滤、异常 ZIP、日期、文件路径和原有单次发布/OAuth 保护。
- 浏览器回归使用模拟 GitHub API，不写入测试文章或测试文件到真实仓库。
